Crystal Conquest: VR Game Marketing Site

Custom front-end work on the marketing site for Crystal Conquest, a free-to-play elemental VR battler from indie studio Mystic Interactive. Working inside Squarespace, I extended the platform with custom CSS and JavaScript to showcase the game's characters, drive Kickstarter support, and hold up on every screen size.

Client
Mystic Interactive
Role

Ongoing
See the game on Steam

The challenge

Squarespace templates are quick to launch but rigid. A game site needs character showcases, motion and clear calls to action, and those aren't available out of the box. The studio needed all of that while keeping the site on Squarespace.

What I built

  • A character codex carousel built on Owl Carousel, with a synced thumbnail strip for browsing the game's mage classes.
  • Character cards with auto-cycling slideshows that bring each class to life without extra clicks.
  • A Kickstarter call-to-action and newsletter signup woven into the page flow.
  • Responsive button rows that scale smoothly with CSS clamp() instead of jumping between breakpoints.
  • An image optimization workflow using pngquant and ImageMagick to keep heavy game art fast to load.

The result

One fast, on-brand home for the game where players can watch, back, join and play. Crystal Conquest launched in Early Access on Meta Quest and Steam in December 2025.
