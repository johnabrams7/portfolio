Automated RSS Publishing for Oracle CMS

An automation tool for a government agency's emergency press-release site on Oracle Content Management, keeping its public RSS feed current every 5 minutes with no manual work and no full-site rebuilds.

Client
Government agency
Role
Technical Lead, Design & CMS Integration
Platform
Oracle Content Management, Oracle Cloud
Team
Me + a back-end developer

The problem

Oracle Content Management only regenerated the site's RSS feed during a full manual site republish. That was slow and easy to forget, and on an emergency press-release site it meant time-sensitive updates could lag behind what the public needed to see.

Who did what

My part

  • Wrote the tool's design spec, defining the fields and functions it needed.
  • Connected the OCM Content Toolkit and server access so scheduled commands could run against the live site.

My developer partner

  • Built the scheduling tool from the spec.
  • Hosted it alongside the toolkit on Atlassian Bitbucket.

How it evolved

Early version

  • Raw cec toolkit commands with typed cron schedules.
  • Validation limiting commands to Oracle's toolkit.
  • Log viewers for stdout, stderr and execution errors.

Finished tool

  • Guided form with command types and structured fields.
  • “Show Compiled Command” preview before saving.
  • Preset schedules, custom cron, and per-task enable toggles.
  • A nightly maintenance window so jobs never collide with toolkit updates.

The result

The feed refreshed every 5 minutes, matching its 5-minute time-to-live, with zero manual effort. The content team no longer had to remember a full republish just to get a press release into the feed.
